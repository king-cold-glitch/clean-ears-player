# Clean Ears Player

Official downloads of **Clean Ears Player**, a video player for Fire TV and Android TV that
mutes bad language while your family watches at home.

Published by Refocus Digital Branding LLC. This repository holds only the official releases;
the source code is private.

## Install

1. On your Fire TV, install **Downloader** (by AFTVnews) from the Amazon Appstore.
2. Go to Settings → My Fire TV → Developer Options → Install Unknown Apps, and turn on
   **Downloader**. No Developer Options? Go to Settings → My Fire TV → About and select your
   device's name 7 times.
3. Open Downloader and enter this address:
   `https://github.com/king-cold-glitch/clean-ears-player/releases/latest/download/CleanEars.apk`
4. Choose **Install**, then open Clean Ears Player.
5. In the app you watch with, choose Clean Ears Player as the external player.

Clean Ears updates itself. When a new version is out, its home screen offers it.

## Works on

- Fire TV devices running Fire OS: Fire TV Stick 4K, Fire TV Stick 4K Max, Fire TV Cube.
- Android TV and Google TV devices, such as onn and NVIDIA Shield.
- Not on Fire TV devices running Vega OS, such as models with "Select" in the name.

## Good to know

- Use Clean Ears only with movies and shows you have the right to watch.
- Filtered playback is altered from the version its makers intended. Clean Ears says so at
  the start of each title and never saves an altered copy.
- Subtitles provided by OpenSubtitles.com.
